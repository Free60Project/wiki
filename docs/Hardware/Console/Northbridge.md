# Northbridge

The Xbox 360's North Bridge is integrated into the system's [Xenos
(GPU)](./Xenos_(GPU).md) and shares a memory controller with it.

- 128-bit GDDR3 Memory Controller @ 1.4 GHz (22.4 GB/s)

- 700 MHz 512 MB GDDR3 RAM (8 chips, each 512 Mbit by 16 bits)
  - Shared System/Graphics memory
  - 5.6 GB/s per chip

- 90/65/45/32 nm ProcessSamsung
  - 500 MB/s read/write (1 GB/s total) SIS [Southbridge](./Southbridge.md) interface (PCI express)
